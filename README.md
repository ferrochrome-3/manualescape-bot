# manualescape-bot
A bot that lets you do manualescape without having to install python (great for skids or if you don't have a PC)

<h2>Dependencies</h2>
Run this command in your terminal to download and install dependencies:
`python3 -m pip install python-dotenv protobuf requests google discord.py`
-# Note: Depending on what OS/distro you are using, you may have to use **python** or **py** instead of python3.

<h2>Setting everything up</h2>
Download all of the files from this repository except the README.md
In the .env file, replace "<bot token here>" with your actual bot token.
Run main.py to start your bot.

The only permission requires is the create commands permission.

# That's it, have fun!
